Phase 1 — UI/UX Directions
ScanSettle — three visual directions
Same 8 screens, three genuinely different treatments. Each screen row below (Merchant Dashboard, Create Payment, Pay by Bank, Bank Selection, Payment Success, Tables Bill, Split Bill, Tip) repeats across the three option rows underneath this cover, so you can compare directly down each column.
OPTION A
Fintech Minimal
White backgrounds, oversized amounts, one restrained accent colour, generous whitespace. Manrope throughout. Stripe/Revolut-style clarity — nothing competes with the number.
OPTION B
Modern Premium
Deep navy + warm gold, elevated cards, layered shadow, a serif/sans pairing (Instrument Serif + Plus Jakarta Sans). Built to feel like a premium banking product, not a utility.
OPTION C
Merchant Utility
Dense data table, sidebar nav, functional status colour-coding, IBM Plex Sans + Mono for numbers. Optimised for a tradesperson or bartender using it fifty times a shift.
Desktop screens (Dashboard, Create Payment) are 1440×900 · Mobile screens are 390×844, actual size.
